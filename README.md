# IPL Analytics Dashboard | Excel

## Project Overview

This project is an interactive Indian Premier League (IPL) Analytics Dashboard created using Microsoft Excel.

The dashboard analyzes IPL data from 2008 to 2024 and provides insights into team performance, toss decisions, venues, title winners, and Player of the Match awards.

## Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## Dashboard Features

### 1. Season Overview

The dashboard provides an overview of each IPL season, including:

- Season
- Winner
- Runner-up
- Player of the Match
- Player of the Series

### 2. Team Performance Analysis

Analyzes matches won by teams based on their decision to:

- Bat first
- Field first

### 3. Toss Decision Analysis

Shows the winning percentage based on the toss decision:

- Bat first
- Field first

### 4. Venue Analysis

Identifies the Top 10 venues based on the number of matches played and analyzes winning patterns based on:

- Batting first
- Fielding first

### 5. Title Winners

A treemap shows the number of IPL titles won by each team.

### 6. Player of the Match Analysis

Shows the Top 10 players based on the number of Player of the Match awards.
